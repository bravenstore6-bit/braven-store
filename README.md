# BRAVEN Store

A premium Arabic-first streetwear storefront for BRAVEN.

## Run locally

```bash
npm install
npm run dev
```

## Included in this first version

- Responsive premium storefront and product collection.
- Product details, sizes, cart and checkout flow.
- Account creation before checkout.
- Admin product control room with add, edit, delete and image URL management.
- Local persistence via browser storage for the prototype.

> Production launch should connect the UI to a secure backend, database, real authentication, storage provider and payment gateway. The current admin shortcut is intentionally a prototype preview and must be protected server-side before launch.
